# Project Operating Instructions

Before working on this repository, always read `PROJECT_MEMORY.md` first. Treat it as required startup context, not optional documentation.

Use `PROJECT_MEMORY.md` as the shared memory for this project:
- Check it before answering operational questions.
- Update it whenever deployment, credentials policy, server topology, ports, automation behavior, or major product decisions change.
- Do not store raw secrets, API keys, passwords, private keys, or Telegram session values in project memory.
- If a secret is relevant, describe where it is stored, for example "server .env", without writing the secret itself.
- If another Codex task appears to have stale assumptions, refresh from `PROJECT_MEMORY.md` and continue from that state.

The user prefers Korean explanations and step-by-step operational guidance.
